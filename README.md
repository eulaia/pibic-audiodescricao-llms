# Geração Automática de Audiodescrições com Modelos Multimodais

Este repositório contém os códigos desenvolvidos no projeto PIBIC sobre geração automática de audiodescrições de imagens utilizando modelos multimodais.

## Modelos utilizados

- GPT-4o
- LLaVA-1.5-7B
- Qwen2-VL-2B-Instruct
- Qwen2.5-VL-3B-Instruct
- Qwen2.5-VL-7B-Instruct

## Execução

Os códigos estão disponíveis no formato de notebooks do Google Colab. Para executá-los, abra o notebook desejado utilizando o botão **Open in Colab**.

As imagens devem ser armazenadas em uma pasta chamada `imagens` no Google Drive:

`/content/drive/MyDrive/imagens`

Alguns modelos podem exigir chave de API ou token de acesso. Essas credenciais não estão incluídas no repositório e devem ser fornecidas pelo próprio usuário.

## Observação

Os códigos foram utilizados em experimentos de geração automática de audiodescrições no contexto do projeto PIBIC.
